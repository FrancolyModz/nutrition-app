# 🍔 Nutrition App

Una aplicación para trackear calorías y macros en comida rápida.

## 🚀 Características

- Catálogo de combos de comida rápida
- Tracking de calorías diarias
- Control de macros (proteína, carbos, grasas)
- Dashboard con resumen diario
- Perfil personalizable

## 📦 Requisitos

- Node.js 16+
- npm o yarn

## 🛠️ Instalación

```bash
npm install
npm run dev
```

## 📝 Scripts

- `npm run dev` - Inicia servidor de desarrollo
- `npm run build` - Build para producción
- `npm run preview` - Preview del build

## 🎨 Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- React Router
